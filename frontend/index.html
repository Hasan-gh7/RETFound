READING THESE RESULTS

Performance needs context.

This is a saved within-dataset test of the APTOS-trained classifier. It is separate from the image you upload.

Known exact-byte overlap and conflicting labels were excluded before sampling. Patient-level independence, near-duplicates, and the checkpoint’s original training split remain unverified.

Any-DR classification uses predicted grade greater than zero. Reference grades 1–4 are positive; grade 0 is negative. A wrong severity grade can still correctly detect DR.

These saved results evaluate RETFound alone, before Jev was added. They do not measure Jev screening accuracy or the combined pipeline.

How to interpret a result

The predicted grade is the class with the highest softmax score. All five scores are shown so that you can inspect the complete model output. These scores are not calibrated probabilities. Uploads pass file validation and a Jev retinal fundus check before RETFound. Automated screening can be wrong; clinical image quality and fundus detection accuracy have not been validated.
